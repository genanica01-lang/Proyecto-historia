# Nicaragua a través del tiempo

Línea de tiempo interactiva con imágenes, mapas, quiz por niveles y comparación de épocas.

## Usar
- Desarrollo: abre `index.html` (necesita todos los archivos juntos).
- Publicar: sube **solo** `dist/index.html` a Netlify, GitHub Pages, etc.
- Regenerar el archivo único tras editar: `python3 build.py`

## Archivos
- `data.js` acontecimientos · `quizdata.js` preguntas · `media.js` imágenes y mapas
- `eras.js` comparación de épocas · `app.js` línea de tiempo y ventanas · `quiz.js` aprendizaje
